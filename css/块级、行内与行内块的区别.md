# block、inline 与 inline-block

## 一、定义

CSS 中元素的显示行为由 `display` 属性决定，最常见的三种类型：

| 类型 | display 值 | 本质 |
|------|-----------|------|
| 块级元素 | `block` | 独占一行，可以设置宽高 |
| 行内元素 | `inline` | 不换行，宽高由内容决定 |
| 行内块元素 | `inline-block` | 不换行，但可以设置宽高 |

## 二、特点对比

| 特性 | block | inline | inline-block |
|------|-------|--------|--------------|
| 是否独占一行 | 是 | 否 | 否 |
| 能否设置 width/height | 能 | **不能** | 能 |
| 能否设置 margin/padding | 四个方向都能 | 仅左右有效，上下无效 | 四个方向都能 |
| 默认宽度 | 父容器的 100% | 由内容撑开 | 由内容撑开 |
| 可以包含其他元素 | 可以包含 block、inline | 只能包含文本或 inline | 与 inline 类似 |

## 三、常见标签

### 块级元素（block）

```html
<div>  <p>  <h1>~<h6>  <ul>  <ol>  <li>  <header>
<footer>  <section>  <article>  <nav>  <form>  <table>
```

### 行内元素（inline）

```html
<span>  <a>  <strong>  <em>  <b>  <i>  <label>  <code>
```

### 行内块元素（inline-block）

没有默认就是 inline-block 的标签，需要手动设置：

```css
button { display: inline-block; }
img { display: inline-block; } /* img 默认是 inline，但行为接近 inline-block */
```

## 四、代码示例

```html
<style>
  .block { display: block; width: 200px; height: 50px; background: lightblue; }
  .inline { display: inline; width: 200px; height: 50px; background: lightcoral; }
  .inline-block { display: inline-block; width: 200px; height: 50px; background: lightgreen; }
</style>

<div class="block">block — 宽高生效，独占一行</div>
<span class="inline">inline — 宽高无效</span>
<span class="inline-block">inline-block — 宽高生效，不换行</span>
```

### 渲染效果解释

- **block**：宽度 200px、高度 50px 生效，后面元素换行
- **inline**：`width` 和 `height` **完全无效**，元素大小由内容决定
- **inline-block**：宽度 200px、高度 50px 生效，且不换行，和前后元素在同一行
