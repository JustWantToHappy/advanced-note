## css三大特性
- 层叠性
- 继承性
- 优先级

### 层叠性
相同的选择器给设置相同的样式，此时一个样式就会覆盖另一个冲突的样式，层叠性就是主要解决样式冲突
层叠性的原则：
- 样式冲突，遵循的原则是就近原则，哪个样式离结构近，就执行那个样式
- 样式不冲突，不会层叠

### 继承性
子承父业，(text-,font-,line-这些开头的样式可以继承，以及color属性，很多其他属性还是不能够继承的)例如
```html
.demo{
    color:red;
    font-size:1.2em;
}
<div class="demo">
<p>sb</p>
</div>
<!--p标签就会继承div的样式-->
```
