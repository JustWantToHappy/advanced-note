## 二分法
- bisect_left(g, x) — 返回第一个 >= x 的位置
- bisect_right(g, x) — 返回第一个 > x 的位置
```python
from bisect import bisect_left

g = [1, 3, 3, 5]
j = bisect_left(g, 0)  # 0  (比所有元素都小，插在最前面)
j = bisect_left(g, 3)   # j = 1  (第一个 3 的位置)
j = bisect_right(g, 3)  # j = 3  (最后一个 3 的右侧)
j = bisect_left(g, 4)   # j = 3  (4 应该插入的位置
j = bisect_left(g, 8) # j = 4(比所有元素都大，等于 len(g))
```
> 使用二分法的时候大部分是一个排好序的序列，也有可能不是一个严格排序的序列

- 总的来说，使用二分法时候需要注意一下两点：
  - 不要陷入死循环，这是使用二分法最容易出现的问题，什么时候需要加一或者减一又或者不加不减这都需要我们合理分析，
  - 数组越界问题，如果我们使用的边界可能会产生越界问题，该如何去处理
