## 普通对象和Map的区别
| 维度 | 对象 (Object) | Map |
  |------|--------------|-----|
  | 键类型 | 字符串 / Symbol | 任意类型 |
  | 键顺序 | 不保证 | 按插入顺序 |
  | 大小 | 手动计算 | `.size` |
  | 遍历 | 不能直接 `for...of` | 可直接 `for...of` |
  | 增删性能 | 较慢 | 更快 |
  | 原型链 | 有，可能冲突 | 无 |
  | 序列化 JSON | 支持 | 不支持（需转换） |
  | 常用场景 | 固定结构、字符串键 | 动态增删、任意键 |
## WeakMap
WeakMap起源于Map，如下是WeakMap和Map区别：

- WeakMap的键只能是对象
并非Map中所有方法都支持，WeakMap可以使用的方法如下：
1. delete
2. has
3. get
4. set
- WeakMap不支持迭代对象的方法
- 当GC清理引用的时候，数据会被删除

## WeakSet
WeakSet对象允许你将弱引用对象存储在一个集合中，weakSet与set的区别:
- weakset只能用于存储对象引用，不能够存放值
- WeakSet对象中存储的对象值都是被弱引用的，即垃圾回收机制不考虑WeakSet对该对象的引用，如果没有其他变量或者属性引用这个对象值，则这个对象将会被垃圾回收掉(不考虑该对象还存在于WeakSet中),所以，WeakSet对象中有多少成员元素，取决于垃圾回收机制有没有运行，运行前后成员个数可能不一致，遍历结束后，有的成员可能取不到了(被垃圾回收了)
- 可使用的方法有add,has,delete,get
- constructor:构造函数，任何一个具有Iterable接口的对象，都可以作为参数
