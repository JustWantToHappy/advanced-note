```javascript
var p1 = /abc/i;

var p3 = new RegExp(/abc/, "i");
//以上三种方式创建出来的正则式一样
```

## 常用的简写形式

- \d就是[0-9]
- \D就是[^0-9]表示除了数字以外的任意字符
- \w就是[0-9a-zA-Z_]。表示数字，大小写字母和下划线。
- \W是[^0-9a-zA-Z_]。表示的是非单词字符
- \s是[ \t\v\n\r\f]。表示空白符，包括空格，水平制表符，垂直制表符，换行符，回车符，换行符.
- \S表示的就是非空白符。
- .就是[^\n\r\u2028\u2029]，几乎表示任意字符，如果要表示小数点，可以使用\.

```javascript
var pattern = /^1[3,4,5,7,8,9][0-9]{9}$/;
//例如:
var p1 = /1[3,4,5,7,8,9][0-9]{1}/;
var p2 = /^1[3,4,5,7,8,9][0-9]{1}$/;
p1.test("139139"); //true
p2.test("139139"); //false
p2.test("139"); //true
```

为什么正则表达式中需要加上^表示开始，$表示结束，如果不设置这两个符号，则字符串可以匹配多次，而设置后表示只能匹配一次

## 两种模糊匹配

正则表达式其实就是模糊匹配，它是一种匹配模式，而模糊匹配有两个方向上的“模糊”:横向模糊和纵向模糊。

- 横向模糊表示一个正则可匹配的字符串的长度是不固定的，可以是多种情况。其实现的方式是量词,比如{m,n}
- 纵向模糊指的是一个正则表达式的字符串，具体到某一个字符时，它可以是不确定的字符，比如[abc]就可以表示abc中任意一个字符

```javascript
var regex = /a[123]b/g;
var string = "a0b a1b a2b a3b a4b";
console.log(string.match(regex));
// => ["a1b", "a2b", "a3b"]
```

## 量词

- {m,}表示至少出现了m次
- {m}表示出现了m次
- ？等价于{0,1}
- +等价于{1,}
- *表示{0,}

贪婪匹配和惰性匹配
尽可能多的匹配(贪婪匹配)

```javascript
var regex = /\d{2,5}/g;
var string = "123 1234 12345 123456";
console.log(string.match(regex));
// => ["123", "1234", "12345", "123456"]
```

尽可能少的匹配(惰性匹配：加上?号)

```javascript
var regex = /\d{2,5}?/g;
var string = "123 1234 12345 123456";
console.log(string.match(regex));
// => ["12", "12", "34", "12", "34", "12", "34", "56"]
```

## 捕获组中的匹配的字符串

正则表达式中使用了圆括号，圆括号里面匹配到的字符串将会被捕获，输出结果中会包含这些字符串。这些捕获到的字符串可以通过正则表达式对象的exec()方法或String对象的match()方法得到。如果正则表达式中没有使用圆括号，那么输出结果中就不会包含任何捕获到的字符串。

```javascript
  const str = "我的邮箱是 hello@qq.com 和 world@163.com";

  // 没有圆括号 — 只返回完整匹配
  const noGroup = /\w+@\w+\.com/g;
  console.log(str.match(noGroup));
  // 输出: ["hello@qq.com", "world@163.com"]
  // 只有整体匹配结果，没有额外信息

  // 有圆括号 — 除了完整匹配，还会返回括号里捕获的内容
  const withGroup = /(\w+)@(\w+)\.com/g;

  // 用 exec() 逐个看
  let match;
  while ((match = withGroup.exec(str)) !== null) {
    console.log(match);
  }
  // 第一次 exec 输出:
  // [
  //   "hello@qq.com",   ← match[0] 完整匹配
  //   "hello",          ← match[1] 第一个括号捕获的用户名
  //   "qq"              ← match[2] 第二个括号捕获的域名
  // ]

  // 第二次 exec 输出:
  // [
  //   "world@163.com",  ← match[0] 完整匹配
  //   "world",          ← match[1] 用户名
  //   "163"             ← match[2] 域名
  // 
```
> 注意，以上case中exec打印结果不是数组，而是类数组对象，打印结构看起来是数组而已

## 如何使用普通的反斜杆\

- 在普通字符串中表示\
  let str='\\'
- 如何创建一个表示反斜杆的正则表达式:

```javascript
//会有两层转换：第一层将字符串转换：\\\\对应的就是两个斜杠\\，然后正则中\\第一个\表示的就是转义字符，后面的\表示的就是反斜杠
let reg = new RegExp("\\\\");
//第一个表示的转义字符，第二个表示的是反斜杠
let reg = /\\/;
//第一个表示的转义字符，第二个表示的是反斜杠
reg.test("\\"); //true
```
> 注意，使用RegExp构造函数以及字符串作为正则式的时候，比如正则表达式\d需要将其转义，也就是\\d

### 字符串匹配
带修饰符g时，match和exec的差异:主要是捕获组是否丢失
- exec：有捕获组
```javascript
	const str = 'a1 a2 a3';
	const re = /a(\d)/g;
	//解释：第一个a1表示正则匹配到的完整内容，第二个"1"表示捕获组匹配的内容，index表示"a1"从字符串第0位开始，input表示输入，groups是命名捕获组，因为正则表达式中没设置，所以undefined
	console.log(re.exec(str));  // [ 'a1', '1', index: 0, input: 'a1 a2 a3', groups: undefined ]
	console.log(re.exec(str));  // [ 'a2', '2', index: 3, input: 'a1 a2 a3', groups: undefined ]

	//上面一个个去匹配，可以改成循环：
	const str = "abc123def456ghi789";
  const regex = /\d+/g;
  let match;
	//regex循环匹配完成之后，lastIndex会重置为0
  while ((match = regex.exec(str)) !== null) {
		/**
		 	 匹配: "123", 起始下标: 3
			 匹配: "456", 起始下标: 9
			 匹配: "789", 起始下标: 15
		 *   
		 */
    console.log(`匹配: "${match[0]}", 起始下标: ${match.index}`);
  }
```
- match：丢失捕获组
```javascript
	const str = 'a1 a2 a3';
  const re = /a(\d)/g	;
  // match：返回所有完整匹配，但丢失捕获组
  console.log(str.match(re));
  // ['a1', 'a2', 'a3']  ← 没有捕获组 (\d) 的信息
```
不带修饰符g的时候：
```javascript
  //不带 g 时两者几乎等价
  const str = 'alice@foo.com';
  const re = /(\w+)@(\w+)/;
  re.exec(str);      // ['alice@foo.com', 'alice', 'foo.com', index: 0, ...]
  str.match(re);     // ['alice@foo.com', 'alice', 'foo.com', index: 0, ...]
```
matchAll结合了exec和match的优点，一次拿到所有匹配，且每个都保留捕获组
```javascript
	//使用matchAll方法，es2020的方法
	const str = 'a1 a2 a3';
	const re = /a(\d)/g;
  for (const m of str.matchAll(re)) {
	/*
		a1 1
		a2 2
		a3 3
	 */ 
    console.log(m[0], m[1]);
  }

```
