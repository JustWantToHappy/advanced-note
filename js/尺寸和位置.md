# 尺寸和位置
使用js操作DOM的时候，尺寸和宽高相关的属性，主要分成以下两部分：
- DOM对象相关尺寸和位置属性
	- 只读属性
		- clientWidth和clientHeight属性
		- offsetWith和offsetHeight属性
		- clientTop和clientLeft属性
		- offsetLeft和offsetTop属性
		- scollHeight和scrollWidth属性
	- 可读可写属性
		- scrollTop和scrollLeft属性
		- domObj.style.xxx属性
- event事件对象相关尺寸和位置属性
	- clientX和clientY属性
	- screenX和screenY属性
	- offsetX和offsetY属性
## DOM对象相关尺寸和位置属性
### 只读属性
#### clentWidth和clientHeight属性
 该属性指的是元素可视部分宽度和高度，即padding+content

#### offsetWidth和offsetHeight属性
这一对属性指的是元素border+padding+content的宽度和高度

#### clientTop和clientLeft属性
这一对属性用来读取元素的border的宽度和高度

#### offsetLeft和offsetTop属性
首先了解offsetParent属性，该属性是获取到当前元素的离自己最近的并且开启定位(position不为static)的祖先元素

如果从该元素向上寻找，找不到这样一个祖先元素，那么当前元素的offsetParent就是body元素

offsetLeft和offsetTop指的是当前元素，相对于其offsetParent左边距离和上边距离，即当前元素的border到包含它的offsetParent的border的距离

#### scrollHeight和scrollWidth属性
元素内部内容超出其宽度和高度的时候，元素内部内容实际的宽度和高度。如果当前元素的内容没有超过其宽度和高度，那么返回的就是元素的可视部分的宽度和高度，即和clientWidth和clientHeight属性值相同

### 可读可写属性
#### scrollTop和scrollLeft属性
当元素其中的内容超过其宽高的似乎，元素被卷起的高度和宽度
#### domObj.style.xxx属性
对于一个DOM元素来讲，它的style属性返回的也是一个对象，并且这个对象中的任意一个属性都是可读写的，例如domObj.style.top，domObj.style.width，但是对于这种方式，**它只能获取到该元素的行内样式，而并不能获取到该元素最终计算好的样式**(也就是说如果不给元素设置style内联样式，就获取不到)，如果要获取到，需要使用到getComputedStyle
## event事件对象相关尺寸和位置属性
对于元素的运动操作，通常会涉及到事件里面的event对象
### clientX和clientY属性
当事件发生时，鼠标点击位置相对于浏览器可视区的坐标，即浏览器左上角坐标的(0,0)
### screenX和screenY属性
screenX和screenY是事件发生时鼠标相对于屏幕的坐标，以设备屏幕的左上角为原点，事件发生时鼠标点击的地方即为该点的screenX和screenY
### offsetX和offsetY属性
鼠标点击位置相对于该事件源的位置，即点击该DOM元素，以该DOM左上角为原点来计算鼠标点击位置的坐标
### pageX和pageY属性
该属性是事件发生时鼠标点击位置相对于页面的位置，通常浏览器窗口没有出现滚动条的时候，该属性和clientX和clientY等价
```html
	<div class="app" style="width:200px;height:300px;overflow:scroll;background-color: red;">
		<div style="height: 2000px;"></div>
	</div>
	<script>
	const dom = document.querySelector(".app")
	//即使子元素滚动了内容，点击父元素的同一个位置，得到的pageX和pageY是不变的，因为pageX和pageY受的是浏览器窗口滚动条的影响
	dom.addEventListener("click", e => {
		console.log(e.pageX, e.pageY);
	})
</script>
```
