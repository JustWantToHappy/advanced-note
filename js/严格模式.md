## 严格模式
严格模式是es5开始新增的一种方式，采用具有限制性js变体的一种方式。设置严格模式的目的，主要有如下几个：
1. 消除js语法一些不合理，不严谨之处，减少一些怪异行为
2. 消除代码运行的一些不安全之处，保证代码运行的安全
3. 提高编译器效率，增加运行速度
4. 为未来新版本的js做好铺垫

### 开启严格模式
`use strict`，比如在script中，放在第一行，以及针对单个函数，放在函数体的第一行
```html
<script>
	"use strict";
	a = 10;//报错：a is not defined
	console.log(10);
</script>
```
```javascript
"use strict"

function demo(){
	"use strict";
}
```
### 普通模式和严格模式区别
1. 未声明的变量在普通模式下可以使用，严格模式下直接报错
2. 删除变量和不存在的属性会报错
3. 函数中相同的形参名会报错
4. 对象中不能有重名的属性：正常模式下，如果对象有多个重名属性，最后赋值的那个属性会覆盖前面的值，严格模式下，这属于语法错误
5. 禁止八进制表示法：正常模式下允许0(零)开头表示八进制，但是严格模式禁止，严格模式下使用字母o表示八进制
6. 普通函数调用内部的this为undefined,普通模式下是全局对象
7. 创建eval作用域：正常模式下，js有全局和函数作用域，严格模式下创设了第三种作用域，eval作用域。正常模式下，eval语句的作用域取决于它处于全局作用域还是函数作用域，严格模式下eval语句本身就是一个作用域
```javascript
"use strict";
var x=2;
console.log(eval("var x=5;x"));
console.log(x);//2，不开启结果就是5
```
8. 不能使用保留字作为标识符：implements,interface,package,private,public等
```javascript
"use strict";
var public="hhh"//严格模式下报错，非严格模式下正常运行
```
