## 原型链
允许对象从其他对象继承属性和方法的一种机制，为什么需要原型链？由于构造器函数实例化出来的每一个实例对象，属性值都是不同的，所以需要每个对象独立一份，但是对于方法而言，所有对象都是相同的，因此我们不需要每个对象都有一份，直接挂在原型对象上共用一份即可。这也是组合式继承的实现原理
![Alt text](image-1.png)

### 注意点
1. 1.prototype对象只存在于构造函数中，用于存储共享属性和方法
2. function.constructor和function.prototype.constructor的区别：function.constructor指向的是function实例的构造函数，function.prototype.constructor指向的function本身
```javascript
console.log((function (){}).constructor===Function)//true
```

### 对象常用API
- Object类静态方法
	- 原型链相关
		- Object.getPrototypeOf(obj)
		- Object.setPrototypeOf(obj,proto)
		- Object.create(proto, props?)
	- 属性描述符相关
		- Object.defineProperty(obj, key, desc)
		- Object.getOwnPropertyDescriptor(obj, key)
	- 遍历对象相关
		- Object.getOwnPropertySymbols(obj)
		- Object.entries(obj)、Object.values(obj)、Object.keys(obj)：遍历对象的可枚举的自有属性
	- 其他
		- Object.is(a, b)：严格相等对比，处理NaN以及-0和+0
		- Object.assign(target, ...src)，浅拷贝合并
		- Object.freeze(obj) / Object.seal(obj) / Object.preventExtensions(obj)：限制对对象属性的增删改
```javascript
const obj={age:10,deep:{
	age:1
}};
//Object.preventExtensions
Object.preventExtensions(obj);
obj.name="hhh"//无法新增属性
delete obj.age;//可以删除属性
obj.age=10;//可以修改属性
console.log(obj);//{deep: { age: 1 } }


//Object.seal
Object.seal(obj);
obj.name="hhh"//无法新增属性
delete obj.age;//无法删除属性
obj.age=10;//可以修改属性
console.log(obj);//{ age: 10, deep: { age: 1 } }

//Object.freeze：什么都操作不了
```
