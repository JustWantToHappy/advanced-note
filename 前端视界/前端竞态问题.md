## 定义
当多个异步请求并发发出，但返回顺序不确定时，后发起的请求可能先返回，导致最终渲染的是「过期」的数据

## 解决方案
只认最后一次发起请求的结果，忽略过期请求

1. 设置版本号(乐观锁机制)，前端当前请求版本号和服务端返回的版本号一致才处理

- 需要服务端支持版本

```javascript
let currentVersion = 0;

async function increment() {
  const res = await fetch("");
  const data = await res.json();
  if (data.version === currentVersion++) {
    //更新前端视图
  }
}
```

2. 标记请求序号（纯前端实现）
```jsx
  function SearchBox() {
    const [keyword, setKeyword] = useState('');
    const [result, setResult] = useState('');
    const requestIdRef = useRef(0); // 记录最新请求的序号

    function handleChange(e) {
      const value = e.target.value;
      setKeyword(value);

      const requestId = ++requestIdRef.current; // 本次请求的序号

      search(value).then((res) => {
        // 只有序号仍是最新的，才更新结果
        if (requestId === requestIdRef.current) {
          setResult(res);
        }
      });
    }

    return (
      <div>
        <input value={keyword} onChange={handleChange} />
        <div>结果：{result}</div>
      </div>
    );
  }
```
3. 每次发送请求之前，取消之前的请求，需要支持AbortController
