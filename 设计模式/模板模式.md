## 模板模式
在父类/基函数里定义算法骨架（固定流程），把可变的步骤延迟到子类去实现。流程不变、细节可变(js中常用高阶函数也可以实现这个能力)
```typescript
abstract class Page{
    //流程固定，可变与不变分离，符合里氏替换和开闭原则
    async render(){
        const data=await this.fetch();
        const html=this.view(data);
        this.mount(html);
        this.track();
    }
    //可变方法：抽象成抽象方法
    abstract fetch():Record<string,any>;
    abstract view(props:any):any;
    //如下两个方法是固定方法
    private mount(html:any){}
    //埋点
    private track(){}
}

class UserPage extends Page{
    fetch(){
        return new Promise(resolve=>resolve([]));
    }
    view(props:any){
        return `<h1>${props.name}</h1>`;
    }
}
```
